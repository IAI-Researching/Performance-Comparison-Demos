# Autonomous Pass@1 Benchmark Protocol: Parameters

Benchmark: ballistics/water-balloon
Protocol: Autonomous Pass@1
Intervention: Zero human-in-the-loop
Filesystem Isolation: macOS Seatbelt (`baseline/sandbox.sb`) blocking `/Volumes`, repository roots, sibling `/private/tmp` runs, and personal host folders (`~/Desktop`, `~/Documents`, `~/Downloads`, `~/Projects`, `~/Developer`).
Environment Policy: Allowlisted child environment (`XDG_*` and `TMPDIR` scoped to `/private/tmp/pcd-sbx-<model>-<id>`), parent-owned telemetry capture outside child writable `RUN_ROOT`.

---

## Harness Execution Commands (Invoked Inside `sandbox-exec -f baseline/sandbox.sb`)

### Track 1: Claude Code (Claude Code 2.1.322 — First-Party Native)
Command:

  --model <model_id> \
  --effort max \
  --dangerously-skip-permissions \
  --no-session-persistence \
  --setting-sources "" \
  --disallowedTools "WebSearch,WebFetch" \
  --output-format stream-json \
  --verbose \
  "<PROMPT>"
